# Hometown Homepage

A simple webpage showcasing my hometown, Milwaukee, top activities. It is devided into three sections: the title, the activities, and the author (the tour guide). 

## Features
- Hover effects that can change an image or make it larger
- Clickable images that direct users to external links

## Skills
- CSS Flexbox
- Flexbox alignment and spacing
- CSS hover effects
- CSS transform
- Web-safe font

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- Git / GitHub
